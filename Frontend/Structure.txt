    1. Breadcrumb Navigation

Frontend Essential Libraries ---

1. React Router DOM – for page navigation
-- npm install react-router-dom
2. React Icons – for icons (cart, user, social icons, etc.)
-- npm install react-icons
3. React Toastify – for notifications (e.g., “Item added to cart!”)
-- npm install react-toastify
4. Axios – for API requests (products, auth, etc.)
-- npm install axios
5. UUID – for unique product IDs or cart items
-- npm install uuid
6. Framer Motion – for smooth animations (cards, transitions)
-- npm install framer-motion
7. React Slick – for sliders / carousels (e.g., Hero section or testimonials)
-- npm install react-slick slick-carousel
8. Formik + Yup – for form handling and validation (Login, Register, Checkout)
-- npm install formik yup
9. React Helmet – for dynamic page titles and SEO
-- npm install react-helmet
10. clsx – for conditional Tailwind class management
-- npm install clsx
